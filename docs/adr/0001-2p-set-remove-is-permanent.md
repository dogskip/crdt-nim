# 2P-Set 의 제거는 관찰 여부와 무관하게 영구적이다

`remove` 는 대상 원소를 아직 추가받지 않았더라도 제거 집합에 넣는다. 처음 코드는 아직 추가되지 않은 원소의 제거를 무효 연산으로 판단해 무시했는데, 그러면 같은 연산 집합도 전달 순서에 따라 결과가 갈린다. add 를 먼저 받은 복제본에서는 제거된 상태로, remove 를 먼저 받은 복제본에서는 살아 있는 상태로 수렴한다. 정의(`lookup(e) = e ∈ A ∧ e ∉ R`)를 그대로 따르면 제거 집합은 조건 없이 커지고, 순서와 무관하게 수렴한다.

## 검토한 대안

- **관찰한 원소만 제거**: 무효 연산을 막아 주지만 전달 순서에 따라 결과가 갈려 CRDT 가 아니게 된다.
- **`remove` 를 API 에서 제외**: 유실되는 연산을 노출하지 않는 대신 2P-Set 의 제거 기능 자체를 잃는다.
